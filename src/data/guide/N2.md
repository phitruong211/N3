# Tổng hợp ngữ pháp JLPT N2

Nov 25, 2026 · @TRUONG

## Cách dùng tài liệu

Tài liệu gom các mẫu ngữ pháp N2 thường gặp trong sách luyện thi (Shin Kanzen Master N2, Soumatome N2), chia theo chức năng. JLPT không công bố danh sách chính thức; danh sách này soạn từ kiến thức có sẵn, chưa đối chiếu với giáo trình cụ thể.

Bản này giả định bạn đã nắm N4 và N3 (xem hai tài liệu trước). Ngữ pháp N2 nghiêng về **văn viết, trang trọng**: tin tức, bài luận, thông báo.

| Ký hiệu | Nghĩa | Ví dụ |
| --- | --- | --- |
| V辞書 / Vます / Vて / Vた / Vない | Các thể động từ (Vます = bỏ ます) | 食べる・食べ・食べて・食べた・食べない |
| 普通形 | Thể thường của V, A, N | 行く・高い・静かだ・雨だ |
| 名詞修飾形 | Thể bổ nghĩa danh từ: Aな → な, N → の | 静かな・雨の |
| Nである | Dạng văn viết của Nだ, hay đi với mẫu N2 | 学生である以上 |

Mẹo ôn: đề N2 hay đặt hai mẫu gần nghĩa cạnh nhau và hỏi sắc thái (khen / chê, chủ quan / khách quan) — học mỗi mẫu kèm sắc thái và cách nối.

## 1. Thời gian, quá trình, kết quả

Nhóm này phân biệt thời điểm (trước, trong, ngay sau) và kết quả cuối cùng (tốt hay xấu) của một quá trình.

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜際(に) | V辞書 / Vた / Nの + 際(に) | Khi, lúc (trang trọng) | お帰りの際は、忘れ物にご注意ください。 |
| 〜に際して / 〜にあたって | V辞書 / N + に際して | Nhân dịp, trước khi bắt đầu (việc quan trọng) | 開店にあたって、多くの方にお世話になりました。 |
| 〜に先立って | N + に先立って | Trước khi (chuẩn bị) | 試合に先立って、開会式が行われた。 |
| 〜次第 | Vます / N + 次第 | Ngay sau khi… thì (sẽ làm ngay) | 資料が届き次第、お送りします。 |
| 〜か〜ないかのうちに | V辞書 / Vた + か + Vない + かのうちに | Vừa mới… đã (gần như đồng thời) | ベルが鳴るか鳴らないかのうちに、学生は教室を出た。 |
| 〜てからというもの | Vて + からというもの | Từ khi… thì (thay đổi hẳn) | 子どもが生まれてからというもの、生活が変わった。 |
| 〜をきっかけに / 〜を契機に | N + をきっかけに | Nhân cơ hội, lấy… làm bước ngoặt | 留学をきっかけに、考え方が変わった。 |
| 〜上で (sau khi) | Vた / Nの + 上で | Sau khi đã (làm cơ sở cho bước sau) | よく考えた上で、返事します。 |
| 〜上で (trong việc) | V辞書 / Nの + 上で | Trong việc, khi làm | 外国語を学ぶ上で、一番大切なのは継続だ。 |
| 〜末(に) | Vた / Nの + 末(に) | Sau một thời gian dài… cuối cùng | 何度も話し合った末、結論が出た。 |
| 〜あげく(に) | Vた / Nの + あげく | Sau cùng thì (kết quả xấu, chán nản) | さんざん迷ったあげく、何も買わなかった。 |
| 〜たところ | Vた + ところ | Khi thử làm thì (phát hiện kết quả) | 先生に相談したところ、賛成してくれた。 |
| 〜ところだった | V辞書 + ところだった | Suýt nữa thì đã | もう少しで車にぶつかるところだった。 |
| 〜きり | Vた + きり | Từ đó trở đi (không xảy ra nữa) | 彼とは去年会ったきりだ。 |
| 〜つつある | Vます + つつある | Đang dần dần (ôn N3) | 景気は回復しつつある。 |
| 〜つつ | Vます + つつ | Vừa… vừa (= ながら, văn viết) | 景色を楽しみつつ、歩いた。 |
| 〜うちに / 〜ないうちに | V辞書 / Vない / A + うちに | Tranh thủ trước khi | 暗くならないうちに帰ろう。 |
| 〜をもって | N + をもって | Với mốc (kết thúc); bằng (phương tiện) | 本日をもって受付を終了します。 |

## 2. Nguyên nhân, lý do

N2 có nhiều cách nói lý do kèm đánh giá: xứng đáng, quá mức, quyết tâm hay suy từ tính cách.

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜だけあって | 名詞修飾形 / N + だけあって | Quả không hổ là, xứng đáng (khen) | プロだけあって、さすがに上手だ。 |
| 〜だけに | 名詞修飾形 / N + だけに | Chính vì… nên càng (tốt hoặc xấu) | 期待していただけに、がっかりした。 |
| 〜あまり(に) | V辞書 / Vた / Nの + あまり | Vì quá… nên (kết quả không mong muốn) | 緊張のあまり、声が出なかった。 |
| 〜ばかりに | 名詞修飾形 + ばかりに | Chỉ vì… mà (hối hận) | 寝坊したばかりに、試験を受けられなかった。 |
| 〜以上(は) | 普通形 (Nである) + 以上 | Một khi đã… thì phải | 引き受けた以上、最後までやる。 |
| 〜上は | V辞書 / Vた + 上は | Đã… thì (quyết tâm, trang trọng hơn 以上) | こうなった上は、やるしかない。 |
| 〜からには | V普通 + からには | Đã… thì phải (ôn N3) | 日本に来たからには、日本語をマスターしたい。 |
| 〜ことだから | Nの + ことだから | Vì là (người đó) nên chắc (suy từ tính cách) | まじめな彼のことだから、遅刻はしないだろう。 |
| 〜ことから | 名詞修飾形 + ことから | Từ việc… nên (căn cứ, nguồn gốc) | 道が湿っていることから、夜中に雨が降ったと分かる。 |
| 〜ことに | Vた / A + ことに | Điều đáng… là (cảm xúc của người nói) | 驚いたことに、彼はもう結婚していた。 |
| 〜につき | N + につき | Vì (thông báo, biển báo) | 工事中につき、通行止め。 |
| 〜ものだから / 〜もので | 名詞修飾形 + ものだから | Vì… (biện minh; ôn N3) | 道が混んでいたもので、遅れました。 |
| 〜というのも | 文 + というのも、〜からだ | Lý do là (giải thích câu trước) | 今日は行けない。というのも、熱があるからだ。 |
| 〜せいか | 名詞修飾形 + せいか | Có lẽ vì (ôn N3) | 寝不足のせいか、頭が痛い。 |

## 3. Điều kiện, giả định

Nhóm điều kiện N2 thường mang ý "nếu không có A thì không thể B" hoặc giả định khó xảy ra.

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜ないことには | Vない + ことには (+ phủ định) | Nếu không… thì không thể | 実際に見ないことには、何とも言えない。 |
| 〜ものなら | V可能 / V意向 + ものなら | Nếu có thể (thì muốn); nếu lỡ làm (thì tệ) | 行けるものなら、今すぐ行きたい。 / 遅刻しようものなら、厳しく怒られる。 |
| 〜限り | V辞書 / Vている / Nである + 限り | Chừng nào còn… thì | 健康である限り、働き続けたい。 |
| 〜ない限り | Vない + 限り | Chừng nào chưa / trừ khi | 努力しない限り、成功はしない。 |
| 〜を抜きにしては / 〜なしには | N + を抜きにしては | Nếu bỏ qua / không có… thì không thể | 彼の協力を抜きにしては、この計画は成功しない。 |
| 〜を抜きにして | N + を抜きにして | Bỏ qua, không tính | 冗談は抜きにして、本題に入りましょう。 |
| 〜次第だ / 〜次第では | N + 次第だ | Tùy thuộc vào | 合格できるかどうかは、あなたの努力次第だ。 |
| 〜としたら / 〜とすれば / 〜となると | 普通形 + としたら | Giả sử; nếu thực sự vậy thì (となると) | 留学するとなると、かなりのお金が必要だ。 |
| 〜ともなると | N + ともなると | Đã đến mức / đã là… thì (lẽ đương nhiên) | 大学生ともなると、自分で考えて行動すべきだ。 |
| 〜ては | Vて + は | Nếu cứ… thì (kết quả xấu); hết lần này đến lần khác | そんなに食べては、太りますよ。 |
| 〜からといって | 普通形 + からといって | Không phải cứ vì… mà (+ phủ định) | お金があるからといって、幸せだとは限らない。 |
| 〜さえ〜ば | N + さえ + Vば | Chỉ cần… là (ôn N3) | 天気さえよければ、出発できる。 |
| 〜ばよかったのに / 〜たらよかったのに | Vば + よかったのに | Giá mà… thì tốt (tiếc nuối; ôn N3) | 傘を持ってくればよかったのに。 |

## 4. Nghịch tiếp, nhượng bộ, đối lập

Các mẫu "tuy… nhưng", "dù… cũng" và "mặt khác" — khác nhau ở mức trang trọng và ở chỗ kết quả đã xảy ra hay chỉ là giả định.

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜ものの | 名詞修飾形 (Nである) + ものの | Tuy… nhưng (thực tế không như mong đợi) | 大学を卒業したものの、仕事が見つからない。 |
| 〜とはいえ | 普通形 / N + とはいえ | Tuy nói là… nhưng (thừa nhận rồi bổ sung) | 春とはいえ、まだ寒い。 |
| 〜にもかかわらず | 普通形 / N + にもかかわらず | Mặc dù (trang trọng) | 大雨にもかかわらず、多くの人が集まった。 |
| 〜ながら(も) / 〜つつ(も) | Vます / A / N + ながらも | Tuy… nhưng (biết mà vẫn) | 体に悪いと分かっていつつも、たばこをやめられない。 |
| 〜にしても / 〜にしろ / 〜にせよ | 普通形 / N + にしても | Dù là… đi nữa thì cũng | 忙しいにしても、連絡くらいできただろう。 |
| 〜にしろ〜にしろ | N1 / V1 + にしろ + N2 / V2 + にしろ | Dù là A hay B thì cũng | 行くにしろ行かないにしろ、連絡してください。 |
| 〜たところで | Vた + ところで | Dù có làm thì cũng vô ích | 今から走ったところで、間に合わない。 |
| 〜反面 | 名詞修飾形 (Nである) + 反面 | Mặt khác (hai mặt của cùng một việc) | 都会の生活は便利な反面、ストレスも多い。 |
| 〜一方(で) | 名詞修飾形 + 一方(で) | Mặt khác, trong khi đó (đối chiếu hai việc) | 米の消費が減る一方で、パンの消費が増えている。 |
| 〜どころか | 普通形 / N + どころか | Đâu chỉ… mà còn / đã không… mà ngược lại | 雨がやむどころか、ますます強くなった。 |
| 〜かと思うと / 〜かと思ったら | Vた + かと思うと | Vừa mới thấy… thì đã (thay đổi nhanh, bất ngờ) | 晴れたかと思うと、急に雨が降り出した。 |
| 〜ところを | V普通 / A / Nの + ところを | Trong lúc… vậy mà (xin lỗi, cảm ơn) | お忙しいところをありがとうございます。 |
| 〜かわりに | 名詞修飾形 + かわりに | Bù lại; thay vì | この仕事は大変なかわりに、給料がいい。 |
| 〜に反して | N + に反して | Trái với (dự đoán, kỳ vọng) | 予想に反して、そのチームが優勝した。 |
| 〜からといって | 普通形 + からといって | Không phải cứ vì… (xem mục 3) | 安いからといって、たくさん買うのはよくない。 |

## 5. Quan hệ, đối tượng, phạm vi

Trợ từ ghép N2 dùng nhiều trong tin tức và văn bản; trước danh từ chuyển sang dạng 〜をめぐる N, 〜に基づく N, 〜における N.

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜をめぐって | N + をめぐって | Xoay quanh (tranh luận, tranh chấp) | 遺産をめぐって、兄弟が争っている。 |
| 〜に基づいて | N + に基づいて | Dựa trên (căn cứ chính thức) | 調査結果に基づいて、計画を立てる。 |
| 〜に沿って | N + に沿って | Dọc theo; theo đúng (kế hoạch, mong muốn) | 川に沿って歩く。 / ご希望に沿って設計します。 |
| 〜に応じて | N + に応じて | Tùy theo, ứng với | 年齢に応じて、料金が変わる。 |
| 〜にこたえて | N + にこたえて | Đáp ứng (kỳ vọng, yêu cầu) | お客様の要望にこたえて、新商品を開発した。 |
| 〜を問わず | N + を問わず | Bất kể, không phân biệt | 年齢・性別を問わず、誰でも参加できます。 |
| 〜にかかわらず | N / V辞書 Vない + にかかわらず | Bất kể (có hay không, nhiều hay ít) | 天候にかかわらず、試合は行われる。 |
| 〜もかまわず | N + もかまわず | Bất chấp, chẳng để ý | 彼は人目もかまわず泣いた。 |
| 〜にわたって | N (khoảng) + にわたって | Suốt, trải dài (toàn bộ phạm vi) | 3日間にわたって会議が行われた。 |
| 〜から〜にかけて | N1 + から + N2 + にかけて | Từ… đến (khoảng ước chừng) | 今夜から明日の朝にかけて、雪が降るでしょう。 |
| 〜を通じて / 〜を通して | N + を通じて | Thông qua; suốt cả (khoảng thời gian) | この地域は一年を通じて暖かい。 |
| 〜において / 〜における | N + において | Tại, trong (= で, trang trọng) | 会議は第一会議室において行われます。 |
| 〜上 / 〜上は | N + 上 | Về mặt (pháp lý, sức khỏe, giáo dục…) | この映画は教育上よくない。 |
| 〜に伴って / 〜につれて | V辞書 / N + に伴って | Cùng với, kéo theo (thay đổi song song) | 人口の減少に伴って、学校が減っている。 |
| 〜とともに / 〜にしたがって | V辞書 / N + とともに | Cùng với; càng… càng (ôn N3) | 時代の変化とともに、価値観も変わる。 |
| 〜をこめて | N + をこめて | Gửi gắm, chứa đựng (tình cảm) | 感謝の気持ちをこめて、手紙を書いた。 |
| 〜に関して / 〜に対して / 〜にとって | N + に関して | Liên quan / đối với / với (ôn N3) | この問題に関して、調査を進める。 |
| 〜にかけては | N + にかけては | Về khoản… thì (giỏi hơn ai hết) | 料理にかけては、彼の右に出る者はいない。 |
| 〜といえば / 〜といったら | N + といったら | Nói đến… thì (といったら: nhấn mạnh cảm xúc) | 彼女の歌のうまさといったら、プロ並みだ。 |
| 〜をはじめ / 〜を中心に / 〜をもとに | N + をはじめ | Tiêu biểu là / lấy làm trung tâm / dựa trên (ôn N3) | 山田氏をはじめ、多くの専門家が参加した。 |

## 6. Mức độ, nhấn mạnh, thêm vào, giới hạn

Nhóm này gồm "không chỉ… mà còn", "chỉ là", "đâu phải lúc…" và các cách nhấn mạnh mức độ cực đoan.

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜ばかりか | 名詞修飾形 / N + ばかりか | Không những… mà còn (hơn nữa) | 彼は英語ばかりか、フランス語も話せる。 |
| 〜のみならず | 普通形 / N + のみならず | Không chỉ… mà (văn viết) | この問題は日本のみならず、世界中で起きている。 |
| 〜はもとより / 〜はもちろん | N + はもとより | …thì đã đành, đến cả… cũng | この店は地元の人はもとより、観光客にも人気だ。 |
| 〜上(に) | 名詞修飾形 + 上(に) | Đã… lại còn (ôn N3) | 道に迷った上に、雨まで降ってきた。 |
| 〜に限らず | N + に限らず | Không chỉ giới hạn ở | この漫画は子どもに限らず、大人にも人気がある。 |
| 〜に限り / 〜に限って | N + に限り | Chỉ riêng (ưu đãi) / riêng… thì lại (trớ trêu) | 先着100名に限り、無料です。 |
| 〜に過ぎない | 普通形 / N + に過ぎない | Chỉ là, chẳng qua chỉ là | それは単なる噂に過ぎない。 |
| 〜にほかならない | N + にほかならない | Chính là, không gì khác ngoài | 成功したのは、彼の努力の結果にほかならない。 |
| 〜どころではない | V辞書 / N + どころではない | Đâu phải lúc (có thể)… | 忙しくて、旅行どころではない。 |
| 〜ほど / 〜くらい (mức độ) | 名詞修飾形 + ほど | Đến mức (ôn N3) | 死ぬほど疲れた。 |
| 〜てまで | Vて + まで | Đến mức phải làm cả… | 借金してまで、新しい車が欲しいとは思わない。 |
| 〜すら / 〜さえ | N + すら | Ngay cả (すら: văn viết) | 彼は自分の名前すら書けない。 |
| 〜こそ / 〜からこそ | N / 普通形 + からこそ | Chính là / chính vì (ôn N3) | 友達だからこそ、本当のことを言うんだ。 |
| 〜というものだ | 普通形 / N + というものだ | Đó mới là, lẽ tự nhiên là (nhận định chung) | 困っている人を助けるのが、友情というものだ。 |
| 〜といった / 〜など | N + といった + N | Như là (liệt kê ví dụ) | 寿司や天ぷらといった日本料理が好きだ。 |
| 〜やら〜やら | N / V辞書 + やら | Nào là… nào là (liệt kê lộn xộn, mệt mỏi) | 引っ越しで、片付けやら手続きやらで忙しい。 |
| 〜といい〜といい | N1 + といい + N2 + といい | Cả A lẫn B đều (đánh giá) | 味といい、値段といい、満足だ。 |
| 〜だけ / 〜だけのことはある | V辞書 / V可能 + だけ; 名詞修飾形 + だけのことはある | Hết mức có thể / quả xứng đáng | 高いだけのことはある。とてもおいしい。 |

## 7. Phán đoán, khả năng

Nhóm này nói về khả năng xảy ra hoặc không thể xảy ra; nhiều mẫu có hình thức phủ định nhưng nghĩa ngược lại (かねない = có thể).

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜かねない | Vます + かねない | Có thể (dẫn đến kết quả xấu) | そんなに無理をしたら、病気になりかねない。 |
| 〜かねる | Vます + かねる | Khó có thể, không thể (từ chối lịch sự) | そのご要望にはお応えしかねます。 |
| 〜得る / 〜得ない | Vます + 得る (える / うる) | Có thể / không thể xảy ra | 地震はいつでも起こり得る。 / そんなことはあり得ない。 |
| 〜っこない | Vます + っこない | Làm sao mà… được (văn nói, phủ định mạnh) | こんな難しい問題、分かりっこないよ。 |
| 〜ようがない / 〜ようもない | Vます + ようがない | Không có cách nào để | 住所が分からないので、連絡のしようがない。 |
| 〜まい | V辞書 (II: Vます) + まい | Chắc không / quyết không (văn viết) | あんな店には二度と行くまい。 |
| 〜に相違ない | 普通形 (N / Aな không だ) + に相違ない | Chắc chắn là (= に違いない, văn viết) | これは彼の仕業に相違ない。 |
| 〜に決まっている | 普通形 (N / Aな không だ) + に決まっている | Nhất định là (chủ quan) | 一人で行くなんて、危ないに決まっている。 |
| 〜わけがない / 〜はずがない | 名詞修飾形 + わけがない | Không đời nào (ôn N3) | 彼がそんな嘘をつくわけがない。 |
| 〜ものか / 〜もんか | V辞書 / A + ものか | Đời nào (quyết không, cảm xúc mạnh) | あんな人に負けるものか。 |
| 〜ではないか / 〜じゃないか | 普通形 + ではないか | Chẳng phải là… sao (ngạc nhiên, nhận định) | なんだ、山田さんじゃないか。 |
| 〜のではないだろうか | 名詞修飾形 + のではないだろうか | Phải chăng là (nêu ý kiến khéo) | この計画には無理があるのではないだろうか。 |
| 〜とは限らない | 普通形 + とは限らない | Chưa chắc là (ôn N3) | 専門家の意見がいつも正しいとは限らない。 |
| 〜ないこともない / 〜ないことはない | Vない + こともない | Cũng không phải là không | 無理をすれば、間に合わないこともない。 |
| 〜かのようだ | 普通形 + かのようだ | Cứ như thể là (ôn N3) | 彼は何もなかったかのように笑っている。 |
| 〜おそれがある | V辞書 / Nの + おそれがある | Có nguy cơ (ôn N3) | このままでは、絶滅するおそれがある。 |

## 8. Cảm xúc, bắt buộc, trạng thái

Nhóm cảm xúc mạnh và "không thể không làm" rất hay vào đề; cùng với các hậu tố tả trạng thái bề ngoài.

### Cảm xúc, bắt buộc

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜てならない | Vて / Aくて / Aなで + ならない | …không chịu nổi, vô cùng (cảm xúc tự nhiên dâng lên) | 将来のことが心配でならない。 |
| 〜てたまらない / 〜て仕方がない | Vて / Aくて / Aなで + たまらない | …không chịu được (ôn N3) | 国の家族に会いたくてたまらない。 |
| 〜ずにはいられない / 〜ないではいられない | Vない bỏ ない + ずにはいられない (する → せず) | Không thể không (tự nhiên muốn làm) | あの映画を見て、泣かずにはいられなかった。 |
| 〜ざるを得ない | Vない bỏ ない + ざるを得ない (する → せざる) | Đành phải, buộc phải (hoàn cảnh ép) | 台風なので、旅行は中止せざるを得ない。 |
| 〜ほかない / 〜よりほかない / 〜しかない | V辞書 + ほかない | Chỉ còn cách | 電車が止まったので、歩いて帰るほかない。 |
| 〜ことか | 疑問詞 (どんなに / 何度) + 名詞修飾形 + ことか | Biết bao nhiêu, biết chừng nào (cảm thán) | 合格の知らせを聞いて、どんなに嬉しかったことか。 |
| 〜ものだ / 〜ものがある | V普通 / A + ものがある | Thật là…; có cái gì đó… (cảm nhận sâu) | 彼の歌には人を感動させるものがある。 |
| 〜てしょうがない | Vて / Aくて + しょうがない | …quá đi (văn nói của 仕方がない) | 眠くてしょうがない。 |

### Trạng thái, khuynh hướng

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜まみれ | N + まみれ | Dính đầy, lấm lem (chất lỏng, bụi) | 子どもたちは泥まみれになって遊んだ。 |
| 〜ずくめ | N + ずくめ | Toàn là (cái gì cũng…; thường tốt) | 今年はいいことずくめの一年だった。 |
| 〜だらけ / 〜がち / 〜気味 / 〜っぽい | N / Vます + だらけ | Đầy / hay / hơi / có vẻ (ôn N3) | 部屋はほこりだらけだ。 |
| 〜げ | Aい bỏ い / Aな / Vたい bỏ い + げ | Trông có vẻ (ôn N3) | 彼女は寂しげな目をしていた。 |
| 〜一方だ / 〜ばかりだ | V辞書 + 一方だ | Ngày càng (ôn N3) | 状況は悪化する一方だ。 |
| 〜っぱなし / 〜たきり | Vます + っぱなし | Để mặc (ôn N3) / từ đó trở đi (xem mục 1) | 水を出しっぱなしにしないでください。 |
| 〜も同然だ | N / Vた + も同然だ | Coi như là, chẳng khác gì | この試合はもう勝ったも同然だ。 |
| 〜ぶる | N / Aい bỏ い + ぶる | Làm ra vẻ, tỏ ra (chê) | 彼はいつも先生ぶっている。 |

## 9. Lời khuyên, đánh giá, chủ trương

Nhóm này nêu quan điểm của người nói: nên / không nên, không cần, kêu gọi, đánh giá mức độ cần thiết.

| Mẫu | Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- | --- |
| 〜ものだ (nên) / 〜ものではない | V辞書 / Vない + ものだ | Vốn nên / không nên (lẽ thường xã hội) | 人の悪口を言うものではない。 |
| 〜べきだ / 〜べきではない | V辞書 + べきだ (する → すべき) | Nên / không nên (ôn N3) | 学生は勉強するべきだ。 |
| 〜ことだ | V辞書 / Vない + ことだ | Nên (khuyên, ôn N3) | 風邪を引いたら、ゆっくり休むことだ。 |
| 〜までもない | V辞書 + までもない | Không cần phải (vì quá rõ) | 言うまでもなく、健康が一番大切だ。 |
| 〜には及ばない | V辞書 / N + には及ばない | Không cần đến mức | わざわざ来るには及ばない。電話でいいよ。 |
| 〜ことはない | V辞書 + ことはない | Không cần phải (ôn N3) | そんなに心配することはない。 |
| 〜に越したことはない | V辞書 / A / N + に越したことはない | Tốt nhất vẫn là, không gì bằng | 安全に越したことはない。 |
| 〜ようではないか / 〜ようじゃないか | V意向 + ではないか | Hãy cùng… (kêu gọi, diễn văn) | 環境を守るために、一緒に努力しようではないか。 |
| 〜わけにはいかない / 〜ないわけにはいかない | V辞書 / Vない + わけにはいかない | Không thể / không thể không (ôn N3) | 仕事があるので、早く帰るわけにはいかない。 |
| 〜わけではない / 〜というわけではない | 名詞修飾形 + わけではない | Không hẳn là (ôn N3) | 全部反対というわけではない。 |
| 〜ことになっている / 〜ことにしている | V辞書 + ことになっている | Theo quy định / thành thói quen (ôn N3) | 毎朝ジョギングすることにしている。 |
| 〜つもりだ (tưởng mình) | Vた / A / Nの + つもりだ | Tự cho là, tưởng là | 彼は何でも知っているつもりだ。 |
| 〜たものではない | Vた + ものではない | Không thể nào… nổi (đánh giá thấp) | こんなまずい料理は食べられたものではない。 |

## 10. Các cặp dễ nhầm và điểm cần nhớ

Đề N2 thường đặt các mẫu dưới đây cạnh nhau; phân biệt bằng sắc thái kết quả và chủ thể cảm xúc.

| Cặp | Khác nhau ở đâu | Ví dụ phân biệt |
| --- | --- | --- |
| 末に vs あげく | Cùng là "sau một quá trình dài"; 末に trung tính / tốt, あげく luôn xấu | 考えた末に決めた / 迷ったあげく、やめた |
| だけあって vs だけに | だけあって: chỉ khen (xứng đáng). だけに: cả tốt lẫn xấu (càng…) | 高いだけあっておいしい / 高かっただけにがっかりした |
| かねない vs かねる | かねない = có thể (xấu). かねる = khó có thể (từ chối) | 事故になりかねない / お答えしかねます |
| ずにはいられない vs ざるを得ない | ずにはいられない: cảm xúc tự thân thúc ép. ざるを得ない: hoàn cảnh bắt buộc | 笑わずにはいられない / 中止せざるを得ない |
| ものの vs とはいえ vs にもかかわらず | ものの: đã làm nhưng chưa đạt. とはいえ: thừa nhận rồi đính chính. にもかかわらず: dù có trở ngại vẫn xảy ra | 買ったものの使わない / 春とはいえ寒い / 雨にもかかわらず実施 |
| を問わず vs にかかわらず vs もかまわず | を問わず: không phân biệt loại. にかかわらず: bất kể có / không. もかまわず: bất chấp (hành vi cá nhân) | 経験を問わず / 天候にかかわらず / 人目もかまわず |
| に過ぎない vs にほかならない | に過ぎない: hạ thấp (chỉ là). にほかならない: khẳng định mạnh (chính là) | 噂に過ぎない / 努力の結果にほかならない |
| ばかりか vs のみならず vs はもとより | Cùng "không chỉ"; はもとより: vế đầu là điều hiển nhiên; ばかりか: vế sau bất ngờ hơn | 大人はもとより子どもも / 子どもばかりか大人も |
| ものだ vs べきだ vs ことだ | ものだ: lẽ thường xã hội. べきだ: nghĩa vụ, đạo lý. ことだ: lời khuyên cụ thể | 年寄りには席を譲るものだ |
| 上で vs 上は vs 上に | 上で: sau khi / trong việc. 上は: đã… thì (quyết tâm). 上に: hơn nữa | 調べた上で / 決めた上は / 安い上に |
| 反面 vs 一方(で) | 反面: hai mặt của cùng một sự vật. 一方で: đối chiếu hai sự việc khác nhau | 便利な反面、危険もある / 米が減る一方で、パンが増える |

### Điểm cần nhớ

- **N2 là ngữ pháp văn viết**: nhiều mẫu chỉ là phiên bản trang trọng của mẫu N3 (において = で, に相違ない = に違いない), nên học theo cặp với mẫu N3 tương ứng.
- **Chú ý hình thức phủ định đánh lừa**: かねない, ないこともない, に越したことはない đều mang nghĩa khẳng định.
- **Bước tiếp theo**: làm đề mẫu chính thức trên [jlpt.jp](https://www.jlpt.jp/samples/forlearners.html), ghi mẫu sai vào bảng phân biệt phía trên.
